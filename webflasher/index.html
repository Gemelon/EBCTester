How it works

Connect via USB

Use a USB data cable – a charge-only cable will not work.

Select the port

Click Connect & install and choose the EBCTester port in the browser dialog.

Install

Confirm the installation. Flashing takes about one to two minutes.

Restart

The device restarts automatically. Then continue with the setup described in the manual.

Requirements

  • Chrome or Edge on a desktop computer
  • USB data cable
  • EBCTester V2 board or a Maker build with ESP32-S3

Erase or keep settings?

  • New device: tick Erase device for a clean installation.
  • Update: leave it unticked to keep your settings – or simply use the built-in OTA update in the web interface.

Troubleshooting

No serial port is listed

Check the USB cable (data, not charge-only) and try another USB port. Close any other program that uses the port, e.g. a serial monitor in VS Code or the Arduino IDE.

The connection fails or flashing does not start

Hold the BOOT button while plugging in the USB cable, release it, and click Connect & install again.

The device does not start after flashing

Press RESET once or unplug and reconnect the USB cable.
