LED function groups

Assign each WS2812 LED a normal function group. Enable OTA to override that LED during firmware updates. Two LEDs are on the board; extensions follow them in chain order.

LED hardware is disabled or the device configuration is inactive. Assignments will be used when LED hardware is enabled.

Tester mode: off = disconnected; green = connected and idle; blue = manual operation; orange = automatic plan. Message frame status: off after 5 seconds without messages; dark green = receiving; bright green = valid-message flash; orange = communication error. OTA: pulsing blue = downloading; pulsing yellow = verifying; steady green = restarting; blinking red = failed.
