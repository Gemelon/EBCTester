Maker Settings

Configure your hardware before activation. Inactive devices run only the access point and web interface. Changes take effect after restart.

Use -1 for unused GPIOs. Assign all pins required by the selected SD bus before activation. Flash/PSRAM, USB and console pins are reserved. HTTP and MQTT are unencrypted unless configured otherwise.

Leave password fields empty to keep the current passwords. Passwords are never returned by the device.

The DS3231 defaults to off in MakerMode and is always enabled in FactoryMode. It stores UTC. At startup and every six hours, NTP takes priority; without NTP, a valid RTC supplies device time. Missing RTC hardware does not block normal services; NTP remains available. The header uses your browser's time zone. RTC INT is reserved; alarms are not used.
