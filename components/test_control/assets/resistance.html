R = (U₁ − U₂) / I₂. Raw values without 20-frame averaging. Time zero: start command after the last idle frame. Actual load onset is between that frame and the first loaded frame. UART sampling rate and resolution particularly limit the 1-second result. Late or implausible results are not reported as resistance.
