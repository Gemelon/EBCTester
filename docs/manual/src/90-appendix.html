Appendix A – Language files

Additional user-interface languages are loaded from the folder /languages on the SD card. A complete template is sd_card/languages/en-custom.json in the repository; a partial Filipino (Tagalog) example is fil.json.

  1. Copy the template, for example as fr.json.
  2. Set "code": "fr" and "name": "Français".
  3. Translate only the values in "strings"; keep all keys unchanged.
  4. Keep placeholders such as {p0}, %u, %s (printf placeholders in the same order).
  5. Save as UTF-8 without BOM, upload to /languages/fr.json (for example in the SD card tab), click Reload languages and select the language in the header.
{
  "version": 1,
  "code": "fr",
  "name": "Français",
  "strings": {
    "language.title": "Langue",
    "...": "..."
  }
}

Missing keys fall back to English. Files named en.json or de.json replace the built-in texts while present. Limits: max. 16 files, 128 KB per file, 1024 entries, 4096 bytes per value, 80 bytes for the name. Language codes use lower-case letters, digits and hyphens (max. 24 characters), for example fr, en-gb. Loading languages from SD requires the option Load additional languages from SD in Maker Settings and an active configuration.

Appendix B – Glossary

AP
Access point – the device's own Wi-Fi network for setup and fallback access.
C-CV
Charging with constant current, then constant voltage (CC/CV).
ConfigAktive
Stored switch that enables the hardware configuration. When off, only the access point and the web interface run.
CSRF
Cross-site request forgery; the token protects against requests from foreign web pages.
D-CC / D-CP
Discharging with constant current / constant power.
DCIR
Direct-current internal resistance, measured with a load pulse.
FactoryMode
Firmware mode of the original board (GPIO 47 high): ready to use with the firmware defaults.
Frame
One message between EBCTester and the tester.
MakerMode
Firmware mode of self-built devices (GPIO 47 low or open): hardware configured in Maker Settings.
NVS
Non-volatile storage in the ESP32 flash for settings.
NTP
Network Time Protocol – see SNTP.
OTA
Over-the-air – firmware update over Wi-Fi.
RTC
Real-time clock – the DS3231 chip that keeps the time while the device is off.
Segment
Section of a test run with one operating mode.
SNTP
Simple Network Time Protocol – time synchronisation over the Internet.
SOC
State of charge in percent.
Test run
Recording of one manual operation, plan or DCIR test with all its measurements.
UTC
Coordinated Universal Time – the time base of all stored time stamps.
WS2812
RGB LED with integrated driver; several LEDs are connected in a chain on one data line.
