Typical workflows

Measuring the capacity of a battery

  1. Battery: enter the battery data and click Apply and save to database (or load a saved battery and click Apply).
  2. Plan: in Automatic, load or create a plan: charge (C-CV) – wait – discharge (D-CC) – wait – optionally charge to storage level.
  3. Connect: in Manual, click Connect (or enable automatic connection). The RX indicator in the header turns green.
  4. Start: in Automatic, click Start plan. You can now close the browser.
  5. Follow: open Measurements at any time. The capacity of the discharge segment in the segment timeline is the measured capacity.
  6. Finish: when the plan is complete, the run status changes to Completed. Give the run a meaningful name in Test run management if you like.

Measuring internal resistance at 50 % state of charge

  1. Apply the battery as above and connect it with four-wire sensing.
  2. In Internal resistance, select Automatic preparation and measurement, enter the usable capacity (ideally the result of a capacity test), the charge parameters and target SOC = 50 %.
  3. Set the pulse current (for example 0.2 C to 1 C, within the battery's limits), check the protection limits, save, tick the confirmation and start.
  4. After completion compare the three results. Repeat measurements under the same conditions (temperature, SOC, rest time) to compare batteries.

Backing up your data

  • Simple: download ebc_a20.db in SD card when no test is running. The file can be opened with any SQLite tool (for example "DB Browser for SQLite").
  • Automatic: set up the MariaDB backup. Delete runs on the SD card only after verifying that they have been transferred.

Changing the hardware of a Maker device

  1. Stop all tests and wait until the recording has finished.
  2. Open Maker Settings, untick ConfigAktive and click Save and restart. The device restarts without driving any hardware pin.
  3. Switch the device off and change the wiring.
  4. Switch it on, enter the new pin assignment, tick ConfigAktive and save again.

Erase all settings over USB

If neither the login password nor the access-point password is known, the settings memory can be erased with a PC. Firmware and SD card data are kept; all settings return to the state of the first start:

esptool.py --chip esp32s3 --port COM5 erase_region 0x9000 0x6000

Replace COM5 with the serial port of the device. If the port is not found, start the device in download mode (hold BOOT, press and release RESET, release BOOT) and press RESET after erasing.

If the problem persists, enable the debug log, reproduce the problem and download the log. When reporting a problem on GitHub, include your hardware and Maker Settings, the firmware version, steps to reproduce and the log – but never passwords or private data.
