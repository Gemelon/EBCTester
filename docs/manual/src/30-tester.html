Maker Settings reference

The Maker Settings tab exists only in MakerMode. On an inactive device it is the first tab; after activation it is found at the end of the Administration section. All values are stored on the device (see Configuration storage) and take effect after the restart that follows Save and restart.

Real-time clock

FieldDefaultMeaning
Enable DS3231 RTCoffUses a DS3231 as offline time source. Takes effect after the restart and only with an active configuration. (FactoryMode always enables it with the pins of the original board.)
RTC INT GPIO14INT/SQW output of the DS3231. Reserved as input only; alarms and wake-up are not used yet. −1 if not connected.
I2C SDA GPIO15I²C data line; required when the RTC is enabled.
I2C SCL GPIO16I²C clock line; required when the RTC is enabled. The bus runs at 100 kHz and needs pull-ups to 3.3 V (on most DS3231 modules already fitted).

At every start a valid RTC time is copied to the device clock before recording and the network services start. When NTP is reachable, it has priority: every successful synchronisation (at the latest every six hours) also writes the time to the RTC. Without NTP, the device clock is refreshed from the RTC every six hours. Both clocks run in UTC; the browser converts the time for display.

An RTC that reports an invalid date or a stopped oscillator (for example after the backup cell was empty) is ignored until the next NTP synchronisation sets it again. A missing or faulty RTC is only reported in the log and never blocks the other functions. Without NTP and without a valid RTC, measurements are stored with the device uptime instead of a date.

Battery tester section

Measurements

The Measurements tab is the dashboard for recorded test runs. All data comes from the database on the SD card, so the page also works on the access point without Internet.

Selecting a test run

  1. Optionally restrict the list with Battery.
  2. Choose a run under Test run. Runs are listed newest first with date, battery, plan and status (or with the custom name given in test-run management).
  3. Click Load data. Refresh list re-reads the list of runs, for example after a new test was started.

The newest run is loaded automatically when the page opens. A running test is refreshed every 15 seconds.

What is shown

  • Summary cards: battery (label, manufacturer, serial number, nominal capacity), the latest current, voltage and capacity, and the run status with current step and cycle.
  • Voltage & current over time: one colour per segment; voltage as solid line (left axis), current as dashed line (right axis). The time axis shows hours:minutes since the start of the run.
  • Capacity over time for every charge or discharge segment, and Capacity per segment as a bar chart (green = charge, red = discharge).
  • Segment timeline: one row per segment with mode, plan step, cycle, the three set-points (SP1–SP3), number of measurements, capacity, start time and duration.

A segment is a continuous section of a run with one operating mode – for example "charge CC/CV" or "wait". To keep the charts fast, at most 1500 points are drawn; the line above the timeline states how many of the stored points are shown ("every n-th"). Segment boundaries are always included. Hover over a chart (or tap it) to see the exact values.

Manual control

The Manual tab gives you direct control of the tester – comparable to the buttons on the tester itself, but with recording.

Status

Shows the live values from the tester (voltage, current, power, capacity), the operating mode with its code, the set-points currently active in the tester, the current battery, the recording state (number of stored measurements) and whether a test plan is active. The badge at the top right shows Disconnected, Connected or the active mode. Stop stops the current operation immediately; it is always available while connected.

Connection

  • Connect starts communication with the tester. The tester's keypad is locked while connected.
  • Disconnect (unlock keypad) ends the connection and unlocks the keypad.
  • Connect automatically (every 3 s): EBCTester tries to connect on its own, for example after switching the tester on.
  • Diagnostic values: model ID reported by the tester, number of valid/invalid messages, age of the last message, and whether a command is waiting for confirmation.

Charge (C-CV)

Charges with constant current until the charge voltage is reached, then with constant voltage until the current falls below the cut-off current.

After Start charging or Start discharging, EBCTester waits up to 10 seconds for the tester to confirm the mode; otherwise it reports an error and sends Stop. Every manual operation is recorded automatically as a test run.

NoteStart buttons are disabled while a command is pending, while another operation or a test plan is running (including its wait steps) and while no tester is connected. The reason is shown below the button.

Creating and editing a plan

  1. Enter a Name for the plan.
  2. In the Step editor, choose the mode, fill in the values and click Add. The step is appended – or inserted after the selected row.
  3. Click a row in the table to select it. You can then Replace it with the editor values, move it (↑ Move up, ↓ Move down) or Delete step. Click the row again to deselect it.
  4. Save to database stores the plan under its name on the SD card. Delete all steps clears the table.

Every change is saved on the device immediately and checked against the limits of the selected tester. Saved plans can be loaded again with the Saved plans list and Load; ↻ refreshes the list.

Running a plan

Connect the tester, check the current battery and click Start plan. The Plan sequence card shows the plan name, current step, cycle, time in the step, status message, battery, tester mode, live values and the number of recorded measurements. The active step is highlighted green in the table.

  • Abort stops the plan and the tester after confirmation.
  • Reset status returns a completed, aborted or interrupted plan to "Ready" so it can be started again.
CautionAfter a power failure or restart, a running plan is not resumed automatically. It is marked Interrupted. Check the battery, then click Reset status and start again if required.

Internal resistance (DCIR)

This tab measures the DC internal resistance of a battery with a load pulse. The battery rests without load, then a defined discharge current is switched on. From the voltage drop the resistance is calculated three times – by default 1, 5 and 10 seconds after switching on:

R = (U1 − U2) / I2

U1 is the average rest voltage at the end of the rest phase, U2 and I2 are the voltage and the measured current at the sampling time. Short times mainly reflect the ohmic resistance (contacts, electrolyte); longer times include polarisation effects.

Preparation methods

  • State of charge already prepared: the battery is already at the desired state of charge. The test starts with the rest phase.
  • Automatic preparation and measurement: the battery is first fully charged (C-CV), then the calculated amount of charge is removed: usable capacity × (100 − target SOC) / 100. The removed charge is integrated from the measured current. The target SOC is therefore an estimate based on the entered capacity, not a measured value. A target of 100 % skips the discharge.

Consistency rules: sample times must increase; the pulse must last at least as long as the last sample time plus the timing tolerance; the rest time must be at least the U1 window; cut-off and charge voltage must be below the maximum voltage; and current × maximum voltage must not exceed the maximum power. In addition, all values must be within the limits of the selected tester.

Running the measurement

  1. Connect the battery with four-wire sensing (separate sense leads) – otherwise the cable resistance is included in the result.
  2. Check all parameters and click Save parameters.
  3. Tick the confirmation box ("Charging parameters and current/voltage/power limits checked for this battery"). Changing any parameter clears this box again.
  4. Click Start measurement. The SD database must be ready.
  5. Follow the progress in the Sequence card; Abort / stop ends the test at any time.

The Results table lists for each sampling time the requested and actual time, U2, I2, the resistance in mΩ and the time stamp. Late or missing samples, too small or negative voltage drops or missing current produce an "invalid" result instead of a wrong number. Onset sampling gap shows the uncertainty of the switch-on moment caused by the interval between tester messages – this mainly limits the accuracy of the 1-second value.

Every DCIR test is stored as a normal test run (raw curve in Measurements) plus structured results. Measurements saved on SD lists the last 20 DCIR tests. Temperature is not measured and is reported as unknown.

NoteDuring a DCIR test all other starts, connect/disconnect and battery changes are blocked. Stop and Abort always remain available. A DCIR test is never resumed after a restart.
